# Blue Moon Render Tools (BMRT)

Larry Gritz's free Renderman-compliant renderer, originally released around 1990, mature by mid-90s. Implemented the [[Renderman]] Interface Specification with extensions Renderman didn't have at the time — ray tracing, radiosity, area lights.

## Function in Paul's formation

For someone learning procedural rendering in the mid-to-late 90s without access to Pixar's proprietary tools, **BMRT was *the* way to actually run Renderman-spec scenes.** Paul's Renderman study went through BMRT specifically.

That detail matters because it's the access path that made the [[autodidact-foundational-stream]] possible. Without BMRT, Renderman was theoretical reading; with BMRT, it was a system you could author shaders for, run, and iterate on. **The free-tool-as-foundation for self-directed learning is part of the map's structure, not just its content.**

## The Gritz lineage

Larry Gritz later co-founded Exluna (acquired by Nvidia), then went to Sony Pictures Imageworks, eventually authoring **Open Shading Language (OSL)** — now a widely-used standard for shader authoring across renderers. The BMRT lineage runs directly into the modern open-source rendering world.

Worth noting: Paul's foundational rendering education runs through a *single named author whose subsequent work has been widely impactful*. Not a textbook tradition, not a faceless tool — a specific person's work. That's structurally similar to how the painters axis runs through named figures rather than through generic "the contemporary fantasy painting tradition."
