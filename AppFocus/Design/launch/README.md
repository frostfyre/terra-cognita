# Terra Cognita Splash Assets for Xcode

Includes a universal Xcode image set plus full-screen reference exports for iPhone, iPad, and Mac. Modern Xcode launch screens should use a storyboard/SwiftUI launch view with this image asset and a matching dark navy background, rather than old static launch-image slots.

Landscape Mac/iPad versions center the portrait artwork over an extended blurred navy/gold background to preserve the composition.
